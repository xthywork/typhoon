# 手機介面、時間軸與媒體匯出整合（2026-10-23）

本次將工作目錄中已實作的服務與介面調整整合至 main，保留先前的 `7c650a3` 路線簡化與平滑風圈調整。

## 服務

- 新增 `systemd/typhoon.service`，供 systemd --user 使用，監聽 `0.0.0.0:18765`。
- server.py 預設埠與相關文件統一為 18765。
- 靜態資源公開清單新增媒體匯出模組與 gifenc；維持明確允許清單。

## 手機介面與時間軸

- 手機採單一同步時間軸，強制使用 CWA 有未來預報點的批次發布範圍，地圖仍顯示歷史路徑。
- 來源與設定以頁首按鈕開啟全畫面面板，保留焦點管理與關閉操作；隱藏桌面進階控制。
- 底部時間軸貼底，縮小倍率選單，新增對應時間的淡色刻度；地圖來源資訊位於更新時間上方。
- 手機與桌面皆提供預設啟用的循環播放。桌面文字按鈕位於同步播放旁，另提供「僅預測範圍」。
- 範圍限制同時套用同步與獨立時間軸的拖動、鍵盤及播放；沒有 CWA 預報時不退回其他來源擴大範圍。

## 圖片與 GIF

- 新增 `media-export.mjs`；桌面入口位於重新整理右側，手機入口位於設定面板。
- PNG 擷取目前時間位置，GIF 依目前勾選時間軸的範圍與倍率播放；沿用來源、圖層、時區及循環設定。
- 提供可拖動、縮放與調整高度的輸出預覽，資訊欄採分欄排版，預覽與輸出共用繪圖函式。
- 最長邊可選 1280、1920（預設）、2560 像素；底圖與 SVG 路線依輸出解析度重新繪製。
- 匯出在瀏覽器內完成；可取消、重新產生及手動下載。保留地圖出處與比例尺。
- 預覽暫時搬移同一張地圖至原生 dialog。關閉時還原 DOM 位置、視角與播放狀態；匯出視窗開啟期間暫停套用新資料。
- 地圖 ResizeObserver 忽略隱藏容器並保留縮放中心，避免預覽及還原時中心偏移。
- gifenc 1.0.3 採 MIT 授權，授權檔位於 `vendor/gifenc/LICENSE.md`。

## 其他分支合併注意

- `bootstrap.mjs` 會將資源版本查詢參數傳給 app.js，app.js 再傳給媒體匯出模組；後續修改程式需同步更新 index.html 的資源版本。
- 請一併帶入 index.html、app.js、map.css、map.js、media-export.mjs、gifenc 與 server.py 的公開清單變動。
- 不要將 API 金鑰、`.env` 或快取資料庫納入版本控制。
- 新增手機瀏覽器案例及共用資料樣本，既有前端案例改用共用樣本與固定虛擬時鐘。
