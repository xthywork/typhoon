# 已儲存歷史颱風與來源命中率整合（2026-10-29）

工作分支：feature/stored-storm-history。整合既有 feature/new-features 尚未提交的來源命中率功能，以及本次歷史颱風選取調整。

## 歷史可選取

- server.py 建立快照時，逐一讀取各來源曾保存的颱風，不再只查 active 清單。
- typhoon.active 為任一有效來源仍將該颱風列為活動的聯集；各來源另保留 active／storedHistory。
- 退出活動清單不會刪除或隱藏已存預報；過期或失敗的來源仍遵守原本活動狀態規則。
- 活動優先、歷史其次；選單有分組及狀態標記，可搜尋名稱、ID、活動／歷史。
- 歷史畫面顯示最後分析時間；來源 hover 清楚標示已儲存歷史與資料筆數，不冒充即時預報。
- 不自動下載或匯入額外歷史資料，僅使用已存在的記錄；亦不對不確定的颱風別名進行猜測合併。

## 一併保留的命中率功能

- forecast_accuracy.py 使用 24h 預報、100km 內的命中率；先去重，再配對 JMA 參考與共同時次。
- 來源下方顯示歷史／本颱風兩欄。hover、鍵盤聚焦或手機點擊可查看詳細口徑。
- 現有即時分析結果為暫估。歷史命中率仍須已結束且具 JMA 定稿參考的合格預報，顯示歷史路線不等於已有定稿驗證。
- 完整研究與限制見 docs/research/2026-10-25-forecast-accuracy.md。
