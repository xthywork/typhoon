# 來源列表預報準確度：研究與建議

研究日期：2026-10-25。狀態：下方保留原始方法研究；使用者後續選定百分比呈現，已實作第一版，規格見文末。

## 建議結論

第一版以「24 小時路徑平均誤差（公里，越小越好）」作為兩個摘要數字。歷史與本颱風必須使用同一指標、預報時效、參考軌跡體系與樣本規則。不要自行把公里換成看似官方的 0–100% 準確率。

來源項目下方可並排顯示：`歷史 84 km｜本颱風 62 km`。此處數字只是版面範例，並非計算結果。列表上方統一註明「24h 路徑誤差 · 越小越好」。詳細說明顯示參考來源、暫估／定稿、樣本數、涵蓋颱風數、統計期間、截止時間與可比性。

## 查閱來源

1. [NHC：Forecast verification procedures](https://www.nhc.noaa.gov/verification/verify2.shtml)：相同有效時間的預報與 best track 位置之大圓距離；區分預報名義起算時間與發布時間；使用同質樣本及 CLIPER／SHIFOR 等基準。
2. [JMA：RSMC Tokyo Annual Report 2024](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/AnnualReport/2024/Text/Text2024.pdf)：第 4 章，以 best track 驗證 00／06／12／18 UTC 預報，依 24／48／72／96／120 小時分開統計；限定起始與有效時間的氣旋階段。
3. [JMA：RSMC Best Track Data](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/besttrack.html)：西北太平洋的官方參考資料來源，可取得年度資料及修訂紀錄。
4. [Met Office：Measures of error](https://www.metoffice.gov.uk/research/weather/tropical-cyclones/verification/summaries/appendix)：DPE、沿路徑誤差、橫向誤差、對 CLIPER 的 skill 等定義。
5. [JMA：Notes on RSMC Tropical Cyclone Information](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/advisory.html)：不同發布時次有 48h／45h、72h／69h 等差異；官方機率圈有明確的機率意義。
6. [NOAA NCEI：IBTrACS](https://www.ncei.noaa.gov/products/international-best-track-archive)：彙整多機構 best track，可作為資料取得與交叉核對管道；必須明確選定其中的參考機構資料。
7. [NII Digital Typhoon：Forecast Accuracy](https://agora.ex.nii.ac.jp/digital-typhoon/reference/forecast/index.html.en)：明確區分使用即時資料與 best track 的驗證，另展示機率圈涵蓋率；其數字不可直接拼接為本網站跨來源排名。

以下歷史期間、樣本警示與介面建議為本專案設計建議，不宣稱是上述機構的統一規定。

## 指標比較

| 指標 | 優點 | 限制與用途 |
| --- | --- | --- |
| 平均位置誤差（Mean DPE） | 直觀、有單位、官方常用，適合來源摘要 | 依預報時效分開；少數大誤差會拉高平均 |
| 中位位置誤差 | 可描述典型情況，較不受極端值影響 | 可能淡化少數嚴重失準，適合詳細資料 |
| 距離的均方根誤差（RMSE） | 對大失誤更敏感 | 不能與平均誤差混標，可列為輔助指標 |
| 指定門檻命中率 | 可呈現百分比，例如 24h 誤差 ≤100km 的比例 | 100km 是人為選擇，不是通用準確率；不同時效須分開 |
| 相對基準技巧分數 | 說明是否比簡單基準好，能考慮預報難度 | 必須先建立同案例基準；可能為負值，不能叫準確率 |
| 沿路徑／橫向誤差 | 區分走太快、太慢與路徑左右偏移 | 較難閱讀，留給詳細分析 |
| 風速／氣壓誤差 | 可衡量強度預報 | 風速平均時間與定義不同；不與位置混成一個總分 |
| 機率圈涵蓋率 | 檢查宣稱的機率是否校準 | 單看涵蓋率會獎勵過大的圈；需連同圈大小及名義機率檢查，不等於中心路徑準確度 |

不建議以預報線到實際路徑的最近距離或圖形相似度作主指標：颱風即使早到／晚到一整天，也可能因走過相同路徑而被誤判為準確。

## 計算規則

1. 保存每個來源的真實預報起算時間 `base`、發布／產品更新時間 `issued`、有效時間、原始座標及版本。計算 24h 時效使用 `valid_time - forecast_origin`，不能使用抓取時間，也不能只以整張產品的更新時間重設時效。
2. 配對相同颱風、相同驗證有效時間：`e_i = great_circle_distance(forecast_i, reference_i)`，單位 km。
3. 同一時效的摘要為 `mean_error = sum(e_i) / N`。0h 分析位置不納入預報分數。24h、48h、72h 不混在一起。
4. 正式跨來源比較優先使用共同的 00／06／12／18 UTC 起算時次與共同有效時間，只比較各參與來源都有資料的案例，公開排除數及涵蓋率。參與來源集合由評估設定決定，不能跟著地圖勾選任意改動。
5. 沒有精確的 24h 預報點時，第一版先排除，不把 21h／27h 或 45h 硬當成 24h／48h。必要插值須作為明確的另一種驗證規格。
6. 參考軌跡優先精確時間匹配；有必要時僅在前後官方分析均存在且間隔不超過 6h 時作大圓／球面時間插值，標記為插值樣本。不得外插、跨長缺口或拿最近一筆分析冒充同時刻真值。
7. 相同預報起算、相同有效時間不得因 API 重抓或更新分析而重複計分。保留最早可確認、在驗證時間之前發行的預報版本；修訂另存。若只能確認最早「收集到」的版本，須明示此限制，不能當成完整原始公告歷史。
8. 預報產品若已有驗證時刻之後的修訂，不能回填成當時的預報。可信的原始歷史公告可以在事後匯入；檢查的是原始發布／修訂時間，不是要求抓取必須發生在有效時間之前。
9. 若只使用機構各自有資料的案例，可提供「本來源可驗證樣本」統計，但不直接標榜跨機構公平排名。共同樣本太少時顯示不足；不把未設定 KMA 造成的空集合誤算為所有來源皆失敗。
10. 固定氣旋階段、區域與期間的納入規則；若無生命史階段欄位，不宣稱已完全重現官方驗證程序。

## 參考軌跡與暫估

- 結束後：優先以同一套 JMA RSMC Tokyo best track 驗證西北太平洋所有來源。它是官方事後估計，不是絕對無誤的觀測真理，亦不能聲稱對 JMA 完全獨立。
- 進行中：建議以 JMA 即時分析作共同暫估參考，待 best track 發布再重算。這能保持同一參考機構，但即時分析與事後分析仍可能不同，必須標為暫估。
- CWA 即時分析可提供另外的參考口徑；若採用，所有來源都要用同一套 CWA 分析，清楚標示，且不能把其結果無標記地混進 JMA 定稿歷史分數。以自家分析驗證自家來源不是獨立真值。
- 不使用不同機構分析的任意平均當作「實際位置」，也不對每個來源選用不同的真值。
- 只統計有效時間已過且參考位置已可用的樣本；尚待驗證不是 0km，也不是 0%。

## 兩個數字的範圍

### 歷史

預設可採最近 365 天「已結束且有定稿參考軌跡」的已收集預報，排除目前選取的颱風。前端須寫「已收集歷史」，不能宣稱涵蓋官方完整歷史。支援日後依年份篩選。

主指標按共同預報樣本計算平均，便於與常見驗證口徑對照；公開樣本數與颱風數。另提供每颱風先平均、再讓每個颱風等權的結果作補充，辨識長壽颱風主導整體分數的程度，兩種聚合不得混標。

### 本颱風

使用目前選取颱風、截至最新資料時間已能驗證的所有合格 24h 預報案例。當颱風仍活動時標為暫估；數字不代表目前這一筆尚未到期的預報已經知道答案。摘要只隨資料與颱風選擇更新，不隨播放游標跳動；批次／節點誤差可在詳細資訊另行呈現。

### 樣本與可靠程度

顯示 N、涵蓋颱風數、資料截止時間與缺漏。小樣本可顯示暫估，但不給冠軍／排名。門檻屬產品規則，應可設定，不能聲稱任意的 N=10 或 N=30 就保證統計可靠。歷史信賴區間宜以颱風為區塊重新抽樣，不能把同一颱風密集更新的預報當作完全獨立事件；颱風數太少時不提供過度精確的區間。

## 本機資料盤點

只讀取既有 SQLite，未觸發新的 CWA API 抓取。盤點當時有 347 筆公告、3 個颱風識別碼；識別碼不保證已完成跨機構同一氣旋核對。

- CHAMPI：CWA 有 53 個產品更新，但只有 21 個不同 `base`；CMA 有 179 筆更新、131 個不同 `base`。不能把產品更新筆數當作獨立預報樣本。
- 主要資料集中在 CHAMPI／INFA；另有只有 CWA 的 `2026-CWA-34` 識別碼，須先確認是否為獨立氣旋或命名前的別名，再納入統計。
- 各來源回溯長度不一致。CHAMPI 的 CMA 記錄可回溯到 10/15，其他多數來源從 10/22 起才有本機記錄；直接拿全量平均比較會混入不同難度案例。
- JMA 本機資料出現 1–24h 與 43–48h 等不規則時效，adapter 目前以產品第一筆位置時間為 `base`。實作前須核對即時分析更新是否沿用了前一次預報；必要時另存真實的 forecast origin／版本，避免把更新後分析時間誤當新預報起算。
- 現有表只用 `(storm, agency, issued)` 識別產品，沒有獨立的首次收集時間／原始預報版本欄位。需補上驗證可追溯的資料結構。
- 現有前端 API 主要輸出活動來源與已匯入歷史；長期評分應由後端直接讀完整預報儲存庫計算，不能只從目前畫面可見來源及批次推算。
- 本機存在分析歷史不代表存在對應的歷史預報；缺少原始預報的舊颱風不能反向製造預報後再評分。

## 已實作的百分比試用版

使用者選定「24h、100km 內命中率」。來源下方並排顯示歷史／本颱風兩個百分比，hover、鍵盤聚焦或手機點擊可查看細節。

- 新增 forecast_accuracy.py，直接讀取既有公告與已匯入的定稿軌跡，不下載新資料。
- 限 00／06／12／18 UTC、精確 +24h 預報點；同一起算僅採最早已儲存的合格版本。
- 本颱風以 JMA 即時分析暫估；已結束且匯入 jma-best-track 的颱風可使用定稿參考。
- 優先使用有合格樣本來源的共同時次；若沒有共同案例，明示為各來源自身樣本而不作公平排名。
- 可在不超過 6h 的分析間隔內作球面時間插值；不外插，不使用尚未發布的參考位置。
- 歷史統計為最近 365 天已結束、有 JMA 定稿參考且儲存了預報的氣旋，排除目前颱風；沒有合格歷史時顯示累積中。
- 詳細資訊含命中筆數、平均／中位公里誤差、樣本期間、截止時間、參考來源、插值數、待驗證與缺參考數，以及暫估與少樣本提醒。
- 少於 10 筆的標記僅為產品提醒，並非聲稱有統計可靠性的正式門檻；不提供名次或冠軍。
- 尚未新增 JMA best track 自動下載，也沒有完整修訂／首次收集時間保存；僅針對既有資料評分，不能宣稱是各官方機構的完整歷史成績。
